INSTALL ON IPHONE
1. Upload these files to any free HTTPS static host such as GitHub Pages.
2. Open the site in Safari.
3. Tap Share > Add to Home Screen > Add.
4. Open Life Tracker from your Home Screen.
5. After the first successful load, the app works offline.

DATA
Your data is stored locally on the device/browser.
Export a backup regularly from Settings.
